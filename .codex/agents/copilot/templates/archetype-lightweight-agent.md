# Archetype: Lightweight Agent

Use this archetype when the parent agent needs a narrow embedded specialty without creating a standalone connected agent.

## Default Characteristics

- narrow reasoning specialty
- parent-local
- minimal conversational independence
- strong structured output preference

## Should Own

- micro-specialty reasoning
- structured intermediate outputs
- one focused job done well

## Should Not Own

- long standalone user conversations
- broad domain ownership
- external connected-agent responsibilities by default
