# Archetype: Orchestrator

Use this archetype when the user request spans multiple domains or specialist capabilities.

## Default Characteristics

- Broad but shallow
- Conversation, routing, and result synthesis focused
- Few direct tools
- Strong escalation and handoff logic

## Should Own

- high-level conversation control
- specialist routing
- assumption management
- final answer composition

## Should Not Own

- large amounts of direct business logic
- deep tool-specific implementation detail
- specialist domain reasoning that belongs in connected or lightweight agents
