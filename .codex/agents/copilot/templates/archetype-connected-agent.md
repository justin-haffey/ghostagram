# Archetype: Connected Agent

Use this archetype when the capability has its own domain boundary, owner, lifecycle, or grounding boundary.

## Default Characteristics

- Standalone domain capability
- Published and connectable
- Same-environment setup requirements
- Own knowledge, tools, and success criteria

## Should Own

- domain-specific reasoning
- domain-specific knowledge and tools
- bounded user outcomes

## Should Not Own

- parent-local micro-specialties
- broad cross-domain orchestration
- another layer of connected agents if it must also be reused as a connected agent elsewhere
